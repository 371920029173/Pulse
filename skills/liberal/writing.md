# 文科档 · Writing and research

Use when skill profile is **liberal** or the user wants copy, outlines, reading notes, text analysis, teaching materials.

## Bias
- Lead with clear structure: thesis, sections, bullets.
- Preserve the user's voice; ask before rewriting tone aggressively.
- Cite sources when quoting; do not invent citations.
- Prefer kb_query / upsert for lasting notes over one-off chat dumps.

## Deliverables
- Outline / summary / polish / comparison table / FAQ
- Keep markdown clean; avoid unnecessary code fences unless showing examples.

相关：`review.md` 做风险审查；`research.md` 做材料结构化。

## 计划（自动化开时）
- 长文 / 多篇交付先 `plan_create`：每步对应一个产物（提纲、初稿、校对、定稿）。
- 一个产物落盘就 `plan_update`，接着做下一步，全部完成再汇总给用户。
