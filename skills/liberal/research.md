# 文科研究笔记
适用：资料整理、论点拆解、文献式笔记（非学术造假）。
1. 先 `kb_query` 看是否已有相关组。
2. 材料分段入库：主张 / 证据 / 反证 / 待核实；边类型用 co_occurrence 或 temporal，禁止无证据因果。
3. 输出给用户时标注来源组路径；缺证据就明说。
4. 多来源 / 多轮调研先 `plan_create`（检索、入库、对照、结论各一步），一步完成就 `plan_update` 接着做，不要中途停下来等确认。

## 定位与并行（研究/写作也适用）

- 要"这个结论在代码/文档的哪里"：`map_whereis "<一句话>"` → `map_lookup <路径>` 看标签与相关组结构知识；
- 要"这次要动/要引用哪些文件"：`map_scope "<任务>"`；
- 并行调研（多主题、多条线索）：`task_spawn({ background: true })` 发出去，`task_status({ ids, wait: true })` 收齐再下结论；
- 结论落库前用 `kb_query` 查证，别让地图里的旧标签当成事实（`stale` 就回去读原文）。
