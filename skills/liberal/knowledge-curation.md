# 文科档 · Knowledge curation

Use when organizing notes, importing documents into the Group KB, or preparing study packs.

## Flow
1. Skim source (md/txt/json) and extract stable claims.
2. kb_upsert under meaningful Groups (theme/project/people), not a flat dump.
3. Link with co_occurrence / weak first; causal only with evidence.
4. Return a short map of what was stored (group paths + node ids).
