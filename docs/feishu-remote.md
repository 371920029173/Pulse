# 手机遥控（飞书）

用飞书私聊一个机器人，就能在外面继续桌面端正在进行的对话。

**为什么是飞书长连接，而不是局域网网页：**

| | 局域网网页方案 | 飞书长连接（当前） |
|---|---|---|
| 公网地址 | 需要内网穿透 / 端口映射 | 不需要 |
| 端口暴露 | 在局域网开 HTTP 端口 | 不开任何端口 |
| 密钥位置 | token 写在 URL 里，易泄露 | 存在本地 `.env`，不出现 |
| 谁能用 | 扫到地址的任何人都能试 | 只有白名单 `open_id` |
| 加密 | 明文 HTTP | 飞书官方通道 |

原理：桌面端**主动向飞书建立 WebSocket 长连接**，消息从飞书推过来。所以你的电脑不需要被外网访问。

---

## 一、在飞书开放平台建应用（约 5 分钟）

1. 打开 [open.feishu.cn](https://open.feishu.cn/app) → **创建企业自建应用**
   - 名字随便，比如 `SHE 遥控`；图标可跳过

2. 左侧 **凭证与基础信息** → 记下两个值：
   - `App ID`（形如 `cli_a1b2c3d4e5f6g7h8`）
   - `App Secret`（点显示后复制）

3. 左侧 **权限管理** → 搜索并开通：
   - `im:message`（读取消息）
   - `im:message:send_as_bot`（以机器人身份发消息）

4. 左侧 **事件与回调** → **事件配置**
   - 订阅方式选 **长连接**（不要选「将事件发送至开发者服务器」，那需要公网地址）
   - 添加事件：`im.message.receive_v1`（接收消息）

5. 左侧 **版本管理与发布** → 创建版本 → 申请发布
   - 个人/测试企业通常可自助通过；企业版可能需要管理员审批
   - **必须发布后长连接才会有事件推送**

## 二、拿到你的 open_id

白名单要填的是 `open_id`（`ou_` 开头），**不是手机号，也不是昵称**。

SHE 提供了**配对模式**来省掉找日志的麻烦。在**第三节填好 App ID / Secret 之后**：

1. 点 **配对模式**（白名单为空时才会出现这个按钮）
2. 在飞书里给机器人随便发一句话
3. SHE 面板的「最近消息」会列出你的 `open_id`，旁边有个 **允许 `ou_xxx…`** 按钮
4. 点一下就自动加入白名单了

> **配对模式下智能体是够不着的** —— 它只会把你的 id 回显给你，不会执行任何指令。
> 所以即使这时候有别人找到这个机器人，也拿不到任何权限。
>
> 也可以用飞书开放平台的「API 调试台」调 `contact.v3.user.batch_get_id`，
> 但不是必要步骤。

## 三、在 SHE 里填配置

两种方式，任选：

**方式 A：界面（推荐）**

1. 打开 SHE → 左侧 **扩展坞**
2. 找到 **飞书遥控** → 点 **配置**
3. 填入 `App ID`、`App Secret`（`授权账号` 可以先留空）
4. **保存配置** → 白名单为空时会出现 **配对模式** 按钮，点它
5. 按上面第二节拿到 open_id 并点「允许」
6. 点 **断开**，再点 **连接**（此时走的是正常模式），状态点变亮即完成

**方式 B：改 `.env`**（改完重启）

```dotenv
SHE_FEISHU_APP_ID=cli_a1b2c3d4e5f6g7h8
SHE_FEISHU_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxx
SHE_FEISHU_ALLOWED_USERS=ou_xxxxxxxxxxxx
```

> 旧版写过不带 `SHE_` 前缀的 `FEISHU_APP_ID`，现在两种都能读，不用改。
> 界面保存时会统一写成 `SHE_FEISHU_*`。

## 四、手机上用

1. 手机装飞书 App，登录**同一个企业/团队**的账号
2. 搜索机器人名字（就是第一步创建的应用名）→ 进入对话
3. 直接发消息，就会送进桌面端当前打开的对话，回复也回到飞书

**群里使用**：把机器人拉进群后需要 **@ 机器人** 才会响应，避免它接群里所有闲聊。

**可用命令**

| 命令 | 作用 |
|---|---|
| `/status` | 看现在接管的是哪个对话 |
| `/help` | 帮助 |

---

## 安全说明

- `App Secret` 只存在本地 `.env`，`/api/feishu/status` 只返回「是否已配置」，**不回传密钥**
- 白名单为空时**拒绝启动**，不会变成一个谁都能用的机器人
- 非白名单账号发来的消息只记一条日志，并回一句「只对已授权账号开放」，不会进入模型
- 手机侧**只能收发对话文本**，没有文件读写、没有终端接口
- 桌面端关机/睡眠后长连接断开，此时手机发消息不会有回复，属预期行为

## 排错

| 现象 | 原因 |
|---|---|
| 报「未配置飞书 App ID / App Secret」 | `.env` 没写或没保存成功 |
| 报「飞书拒绝了这个应用凭据（code 10003）」 | App ID / Secret 复制不全或有空格 |
| 报「请先填写允许使用的飞书用户 open_id」 | 白名单为空；用「配对模式」先拿 id |
| 连上了但发消息没反应 | 应用没发布；或没订阅 `im.message.receive_v1`；或订阅方式不是「长连接」 |
| 面板显示 `不在允许名单内` | 你的 `open_id` 没在白名单里，点旁边的「允许」按钮 |
| 回复被截断 | 超过 `SHE_FEISHU_MAX_REPLY_CHARS`（默认 4000 字） |

> 连接前 SHE 会先向飞书换取 tenant access token 验证凭据，所以**凭据错会当场报错**，
> 不会出现「显示已连接但其实没通」的假成功。
