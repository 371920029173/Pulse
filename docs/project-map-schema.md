# 项目地图 schema（P0，形状定死）

> **状态：实验功能。** 存储格式与 `map_*` 查询已经可用并且在门禁里（`check:map`），
> 但接口仍可能随使用反馈调整；改字段要按本文第 9 节升版本并写迁移。
> 目前没有界面入口，只有命令行（`pnpm map:build` / `pnpm map:query`）与将来的 agent 工具。

> 目的：给**模型**用的代码地图。模型的问题不是"怎么写代码"，而是"**哪里是干什么的**"。
> 规模目标：**100k 文件**。不引 embedding；检索 = 结构 + 词法 + 组结构共振。
> 本文是形状契约：改动这里的决定等于改存储格式，要先改版本号并写迁移。

## 0. 入口在哪（找地图的人从这里开始）

地图**没有**一个叫 `map/` 的文件夹，也没有独立页面。它的入口只有三个，按可用性排：

1. **SHE 界面**：命令面板（Ctrl+K）→「项目地图（只读）」。面板读的是**服务端当前工作区**的地图；
2. **命令行**（在当前工作区的根目录下跑）：`pnpm map:build` 建图，`pnpm map:query tree|lookup|whereis|scope|impact|contracts|verify` 查询；
3. **给模型的工具面**（P5 之后）：`map_*`，走同一份数据。

### 「没有地图」是什么意思

地图是**一个工作区一套**：`.she/map/` 只会出现在**跑过 `map:build` 的那个工作区根下**，其它工作区天然没有。
所以在别人的仓里找不到 `.she/map` 是正常的，不是坏了。三种处理：

- 在那个工作区里建一份：`cd <那个工作区> && node <本仓>/scripts/map-build.mjs`（脚本按当前目录建图）；
- 借别处的用：`pnpm map:query adopt <别的工作区根> [--prefix 旧路径=新路径 …]` —— 只写引用、不复制正文；
- 什么都不做：`map_tree` 会回一句「还没有地图：先跑 pnpm map:build」，而不是给你一张空图。

## 0. 一句话架构

**形状无关核心 + 三个视角适配器**（包 / 仓 / 构建单元），交付物是一组 `map_*` 工具，白板只是只读渲染。

## 1. 节点身份：`(branch, path, sha1)` —— 允许孪生

一个文件在三处需要区分：

| 概念 | 键 | 用途 |
|---|---|---|
| 节点（孪生体） | `branch:path` | 同一路径在不同分支上**并存**，各自带标签与注记 |
| 内容身份 | `sha1` | 标签绑内容：内容变了标签自动 `stale`，但**不删除** |
| 版本锚 | `rev` | 这条标签/注记描述的是哪一版（合回主干后能追溯） |

- **孪生文件是特性，不是冲突**：`main:src/a.ts` 与 `feat/x:src/a.ts` 是两个节点，各自积累标签与注记，可以挂到不同组上。
- 跨越分支的"同一个文件"由 `path` 聚合视图（`map_tree(view=')` 默认只显示当前分支；`map_lookup(path, alts=true)` 才列出孪生体）。
- **回收**：分支删除或长期不合并的孪生体，按"最近访问 + 是否已合并"两年后回收（策略在 P8 实现，schema 先留 `lastSeen`）。

## 2. 三级粒度

```
目录节点   ── 组的容器（目录轴），标签由子节点聚合生成，模型可覆盖
  文件节点 ── label / what / when 三段
    符号节点 ── 导出名 → 位置 + 引用数（轻表，按需解析）
```

## 3. 组是 DAG，不是树

一个文件可同时属于：**目录轴**（`dir:packages/kb/src`）、**功能轴**（`feat:context-compaction`）、**层轴**（`layer:infra`）。组节点本身也是地图节点，可以与 KB 的组路径一一对应。

## 4. 边：每条都带证据与置信度

```ts
{ from, to, kind, confidence: 'certain' | 'candidate', evidence: string[], falsifiers?: string[] }
```

- `certain`：机器可复核（"B 的 import 语句指向 A"）。
- `candidate`：**潜在威胁**档 —— 名字相近、单端证据、契约未对齐。**永不伪装成 certain**（与 KB 的边类型纪律一致：共现/时序不升格为因果）。

### 契约边：用户提的"逻辑链条 + 对账"

1. **创建时记录潜在依赖**：API/路由/事件/表/配置键被定义的那一刻，地图记下 `{ key, provider, shape }`。
2. **两侧对账**：把"提供端"（路由定义、event emit、表写入、env 读取）与"使用端"（fetch 调用、listen、查询、process.env）按 `key` 配对。
3. **产出两类**：
   - 两边都能定位且形状相容 → `certain`，直接写出来；
   - 只有一端、或形状不相容（字段名/方法/路径不符）→ 标记为 `candidate` 并进 **潜在威胁清单**（`map_impact(..., threats=true)` 能列出来）。

这把"推理"降级成"证据准备 + 对账"，不需要模型猜。

## 5. 存储：分片 + 增量

```
.she/map/index.json          根分片：版本、分支、分片列表、跨分片边、统计
.she/map/shard-<key>.json    一顶级目录/包一个分片（key = 目录名哈希前 8 位）
.she/map/symbols.bin         符号轻表（排序数组 + arena，不是一符号一对象）
```

- 加载 O(当前视野)，不是 O(仓)。
- 写盘：脏分片才写，原子替换（tmp + rename），写前比对 mtime；冲突按字段并集合并，**绝不整文件覆盖**。
- 分片损坏按 `state-file.ts` 规则搬走（`*.corrupt-<ts>`），不覆盖、不静默重建。

## 6. 排除与安全

不索引：`.gitignore` 命中项、二进制（NUL 探测）、单文件 > 2MB、`node_modules`、`dist`、`.git`、**`.env` 与任何密钥/凭据文件名**（与 KB 禁忌一致）。排除表本身进 index，便于审计。

## 7. 预算（硬约束，不是愿望）

| 操作 | 上限 |
|---|---|
| `map_tree(depth=1)` | 15ms / 2000 token |
| `map_lookup` | 10ms |
| `map_whereis` | 100ms，扫描 ≤2000 节点（分片打分 → 展开 top-k） |
| `map_impact` | 150ms |
| 每轮写盘 | 20ms |
| 冷建 100k | 3–5 分钟，可中断续跑 |
| 索引体积 | ≤ 仓库 3–5% |

超预算时**先塌缩最不活跃的子树**：脏 / 热 / 有注记的子树永不塌缩。

## 8. 新鲜度

每个标签与注记都绑 `sha1 + rev`。内容变了：`stale = true`，保留原文（"之前什么样"要留得住），`map_lookup` 必须明说"这描述的是 N 个提交前的内容"。**宁可说不知道，也不许把过期标签当真的用。**

## 9. 版本

`schemaVersion: 1`。字段只增不改语义；改语义必须升版本并写迁移脚本。
## 10. 收编（引用优先 + 写时复制）

地图是**一个工作区一套**（`.she/map/`，随工作区走，不进 git）。想把别处工作区的知识搬过来时走「收编」，而不是复制：

- `pnpm map:query adopt <外部工作区根> [--prefix 旧路径=新路径 …]`；
- 收编**只写引用**（外部根 + 分片 + 路径 + 当时的 sha1），标签/注记正文留在外部，本地磁盘增长≈被真正改过的条目数；
- 读的时候回外部取，并按本地内容 sha 判新鲜度：不一致就标「外部那版已与本地不同，只作参考」；
- **改**某条时才落地（写时复制），并记 `derivedFrom`（出处 + 原 sha1），同时删掉那条引用；
- 外部不可达时显示「取不到，不是不存在」，绝不静默消失；路径对不上就进「未对齐」清单，**不按文件名猜**。
